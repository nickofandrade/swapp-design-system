Conectar Swapp à sua IA

Inclua as instruções do Swapp no contexto do seu agente. Use o documento estendido para geração de UI e o compacto para conversas curtas.

  1. Claude Code: copie CLAUDE.md para a raiz do projeto ou referencie dist/DESIGN.md.
  2. Cursor: use o arquivo .cursor/rules/swapp-design.mdc.
  3. Codex / ChatGPT: coloque AGENTS.md na raiz do projeto ou anexe dist/DESIGN.md como contexto.
  4. Outras IAs: forneça dist/DESIGN.compact.md ou o Extended no system prompt.
  5. Ferramentas de design: importe dist/tokens.json no Tokens Studio ou Style Dictionary.
